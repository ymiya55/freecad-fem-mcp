# 最初の解析

[English](first-analysis.md) · [READMEへ戻る](../README.ja.md)

この解析は、FreeCAD FEM MCPの「Hello World」です。鋼製片持ちはりへ一様な横圧力を与え、変位と応力を確認します。内容を承認するまでモデルは保存しません。

このMCPはFEM解析機能だけを提供し、CADモデリングは行わないため、直方体のはり形状はFreeCADで手動作成します。

## 解析目的

次の直方体片持ちはりの変形と応力分布を求めます。

| 項目 | 値 |
|---|---|
| 長さ | 100 mm |
| 幅 | 10 mm |
| 高さ | 10 mm |
| ヤング率 | 210 GPa |
| ポアソン比 | 0.30 |
| 密度 | 7,850 kg/m³ |
| 拘束 | 一方の端面を固定 |
| 荷重 | 上面へ0.1 MPaの圧力 |
| メッシュ | 5 mm、一次3D要素 |

下向きに曲がり、自由端で変位が最大、固定端付近で曲げ応力が最大になることを確認します。初等はり理論による概算値は、自由端変位が約`0.071 mm`、最大曲げ応力が約`30 MPa`です。粗い3Dメッシュや実際の圧力設定によって差が生じます。

## 事前準備

[セットアップ](setup.ja.md)を完了し、FreeCAD GUIを一つだけ起動します。CodexまたはMCPクライアントでは新しいタスクを使用してください。

FreeCADで次を行います。

1. 新しいドキュメントを作成します。
2. Partワークベンチへ切り替えます。
3. `Length = 100 mm`、`Width = 10 mm`、`Height = 10 mm`のBoxを作成します。
4. オブジェクト名を`Cantilever`へ変更します。
5. 3Dビューへモデル全体を表示します。

保存は任意です。この手順はアクティブドキュメントを操作し、自動保存しません。

## 1. 接続とモデルを確認する

次のプロンプトを送ります。

```text
freecad-fem MCPだけを使ってget_statusとinspect_documentを実行して。
FreeCADへ接続できていることと、アクティブドキュメントに
Cantileverというsolidが一つあることを確認して。
まだドキュメントを変更しないこと。
```

bridgeの接続と対象solidが確認できるまで先へ進みません。

## 2. 解析と材料を作成する

次を送ります。

```text
freecad-fem MCPだけを使って、アクティブドキュメントへ
線形静的SolverCalculiX解析を作成して。
ヤング率210e9 Pa、ポアソン比0.30、密度7850 kg/m^3の
等方性鋼材をglobal材料として割り当てて。
analysis IDを報告し、拘束と荷重はまだ追加しないこと。
```

返されたanalysis IDは同じ会話内で引き続き使用します。

## 3. 一方の端面を固定する

FreeCADの3Dビューで、はり始端側の`10 mm × 10 mm`端面を選択します。その後、次を送ります。

```text
get_selectionを使い、CantileverのFaceが一面だけ選択されていることを確認して。
現在のGUI選択を使って、先ほどのanalysisへfixed境界条件を追加して。
選択が空、またはFace一面でなければ停止すること。
```

FreeCADのモデルツリーに固定拘束が追加されたことを確認します。

## 4. 圧力を与える

選択を解除し、長い`100 mm × 10 mm`の上面を選択します。その後、次を送ります。

```text
get_selectionを使い、CantileverのFaceが一面だけ選択されていることを確認して。
現在のGUI選択を使って、analysisへ100000 Paの圧力を追加して。
選択が空、または上面のFaceでなければ停止すること。
```

FreeCADの正の圧力は選択面へ向かって作用します。解析前に荷重記号の方向を確認してください。

## 5. メッシュ、検証、解析を実行する

次を送ります。

```text
analysisに要素サイズ5 mmの一次3D Gmshメッシュを作成して。
get_jobでメッシュジョブが終了するまで確認して。
成功した場合はvalidate_analysisをstrict modeで実行し、
警告とエラーをすべて報告して。
検証に成功した場合だけCalculiXを開始し、solver jobが終了するまで確認して。
いずれかのjobが失敗した場合は直ちに停止すること。
```

CalculiXを開始する前に、材料、拘束、荷重、メッシュが揃っていることを検証します。

## 6. 結果を確認する

次を送ります。

```text
完了したanalysisからdisplacementとvon_misesの結果を取得して。
最大値と単位を報告して。FreeCADへdisplacement結果を表示し、
isometric表示、全体表示を行ってviewportをキャプチャして。
ドキュメントは保存しないこと。
```

次の工学的チェックを行います。

- 自由端で変位が最大になっていること。
- 変位方向が圧力方向と一致すること。
- 固定端付近で曲げ応力が最大になっていること。
- 結果が有限値で、はり理論の概算と大きく矛盾しないこと。
- 粗いメッシュの応力ピークを収束済み設計値として扱わないこと。

## 7. 確認後に保存する

設定と結果に問題がなければ、`save_document`の実行を依頼します。新しいパスへの保存には許可ルートが必要です。既存ファイルの上書きには、さらに明示的な`overwrite=true`と現在のドキュメントrevisionが必要です。

## この解析で確認した範囲

解析全体の経路を実行しました。

```text
FreeCADモデル → 確認 → 解析 → 材料 → 拘束 → 荷重
→ Gmshメッシュ → 事前検証 → CalculiX → 数値結果 → GUIコンター
```

実務での進め方は[Daily workflow（英語）](daily-workflow.md)、その他の解析種類は[解析機能](capabilities.ja.md)を参照してください。
