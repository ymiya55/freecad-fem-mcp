# 日常的な解析ワークフロー

[English](daily-workflow.md) · [READMEへ戻る](../README.ja.md)

このワークフローは、AIアシスタント、FreeCADのアクティブドキュメント、CAE技術者の工学的判断を同期させながら解析を進めるためのものです。

## セッションを開始する

1. FreeCAD GUIを一つだけ起動します。
2. FreeCADで手動作成するか、別のモデリングツール/MCPで形状を準備します。その後、対象モデルを手動で開くか、許可ルート内のパスに対して`open_model`を使用します。
3. MCPクライアントで新しいタスクを開始します。
4. 変更前に`get_status`と`inspect_document`を実行します。
5. アクティブな`document_id`、document revision、geometry object、予定する解析種類を記録します。

最初は短い確認プロンプトを使用します。

```text
freecad-fem MCPだけを使ってstatusとアクティブドキュメントを確認して。
モデルobject、既存analysis、現在のrevisionを要約して。
変更や保存は行わないこと。
```

## 最初に解析の意図を定義する

ツールを呼び出す前に、次を明示します。

- 解析種類とモデル次元
- 材料モデルと単位
- 支持条件の理想化
- 荷重定義と座標系
- 接触・結合の仮定
- メッシュサイズ、要素次数、局所細分化の方針
- 必要な結果量
- 検証方法または比較対象

AIアシスタントに解析条件を簡潔な表で復唱させます。曖昧なFace、符号、単位、参照点は、モデルを変更する前に解決してください。

## チェックポイントごとに解析を構築する

### チェックポイント1: 解析と材料

解析を作成して材料を割り当て、再度ドキュメントを確認します。固有振動解析では密度を確認します。材料非線形では、硬化則とすべての降伏点をSI単位で確認します。

### チェックポイント2: 要素の理想化

1D/2Dモデルでは、メッシュ作成前に必要なbeam断面、beam回転、shell板厚、formulation、領域材料をすべて割り当てます。未割当または重複しているEdge/Face領域がないことを確認します。

### チェックポイント3: 拘束と荷重

GUI選択を使用する条件を追加する直前に`get_selection`を実行します。条件を追加するたびに、FreeCADツリーに作成されたobjectとviewportに表示された方向を確認します。

新しい解析手順では、`add_constraint`の互換用形式よりも`add_boundary_condition`と`add_load`を優先します。remote条件と接触・結合には明示的なtargetを使用します。

### チェックポイント4: メッシュ

`create_mesh`を開始して返されたjob IDを保持し、terminal stateに到達するまで`get_job`を実行します。解析前にFreeCADで次を確認します。

- 1D/2D/3Dの理想化が正しい
- 応力勾配付近の要素サイズが十分である
- 二次要素の設定が意図どおりである
- 欠落しているbodyや領域がない
- 要素数とaspect ratioが妥当である

### チェックポイント5: 解析前検証

`validate_analysis(strict=true)`を実行します。すべてのエラーを停止条件として扱います。警告をAIアシスタントに抑制させるのではなく、工学的判断として内容を確認してください。

### チェックポイント6: 解析実行

検証に成功した場合だけ`start_analysis`を開始します。返されたjobを`get_job`で確認し、queuedまたはrunningの間に重複した解析を開始しないでください。実行中jobが不要になった場合は`cancel_job`を使用します。

## 結果を確認する

判断に必要なfieldだけを取得し、次を確認します。

- 単位と変形倍率
- 変位方向と拘束自由度
- 応力位置と、ピークが特異点によるものか
- モードの順序と物理的なモード形状
- 座屈事前荷重と符号
- 3D展開されたbeam/shell結果の元モデル次元
- 手計算、過去の解析、benchmarkとの整合性

追跡可能な表示確認には`show_result`と`capture_gui`を使用します。レポート画像を撮る前に、
`inspect_document`で正確なobject名を取得し、`set_visibility`の`isolate`でメッシュまたは
結果pipelineだけを表示できます。撮影後は`show_all`ですべてのGUI表示可能objectを復元します。
スクリーンショットは表示状態の記録であり、メッシュ収束やモデル妥当性の証明ではありません。

## 保存して終了する

MCPは自動保存しません。`save_document`の前に次を行います。

1. ドキュメントを確認し、現在のrevisionを確認する。
2. 保存先パスを確認する。
3. 既存ファイルを上書きしてよいか判断する。
4. モデル、解析仮定、ソルバーバージョン、結果確認を一緒に記録する。

検討段階では、開始時のモデルを上書きせず、新しいファイルへ保存してください。

## 推奨プロンプト形式

```text
freecad-fem MCPだけを使用すること。

目的: [工学的な確認事項]
モデル: [アクティブドキュメントと次元]
材料: [SI単位の物性値]
拘束: [entityと拘束自由度]
荷重: [entity、値、符号、座標系]
メッシュ: [次元、サイズ、次数]
結果: [必要なfieldまたはmode]

チェックポイントごとに作業して。選択は使用前に確認し、解析前にvalidateし、
すべてのjobの完了を待つこと。エラーがあれば停止して。
最終モデルを私が明示的に承認するまで保存しないこと。
```

最初の一連の解析には[最初の解析](first-analysis.ja.md)を使用してください。
